Smart Digital Transit & Attendance Safety Monitoring System for Government School Commuters

Executive Summary: This document demonstrates the complete execution and running interface of SchoolRoute TN. Designed specifically for underprivileged Tamil Nadu government school students traveling under the 100% Free Commuter Bus Scheme, it completely eliminates the need for students to carry smartphones. Using printable laminated 2D QR bus passes, camera-based driver verification (jsQR), on-bus AIS-140 physical panic buttons, and real-time cellular SMS dispatch via Vercel serverless gateways, the platform ensures total commuter safety and attendance integrity.

Screen 8: In-Browser jsQR Video Stream Camera Scanner

High-speed HTML5 Canvas camera scanner using the jsQR library to scan student passes on the bus entry step within milliseconds without freezing.

SCREENSHOT 08 • jsQR CAMERA SCANNER MODAL ENGINE: Real-Time HTML5 Canvas Video Frame Loop
1. Continuous Non-Blocking Video Loop Runs requestAnimationFrame(scanVideoLoop) unconditionally on every frame; unrecognized or damaged codes never freeze the stream.
2. Sub-Second Boarding Verification Instantly extracts the encrypted payload, marks student as On Board, and dispatches a cellular SMS to parent mobile.
3. Frame Throttling & 2-Second Debounce Prevents rapid duplicate scans and multiple SMS charges using timestamp cooldowns and React useRef locks.
4. Manual EMIS ID Fallback Provides manual text input for entering student registration numbers if camera lens is smudged or pass is physically damaged.
Engineering Details: Implemented in src/components/DriverConsole.jsx#L150-L240; integrates Web Audio API for two-tone chime upon scan.

Technical Problem-Solving Matrix (Hurdles & Solutions)

Summary of major engineering hurdles encountered during the development of SchoolRoute TN and the exact architectural solutions implemented to sort them:

Challenge Encountered Underlying Technical Bottleneck Implemented Solution & Architecture
1. Browser CORS Block on SMS APIs Direct browser fetch() calls to SMSMobileAPI and Fast2SMS failed due to Cross-Origin Resource Sharing restrictions. Engineered Vercel Serverless Functions (api/smsmobile.js and api/fast2sms.js) acting as cloud reverse proxies with explicit CORS headers.
2. Vercel SPA Route Hijacking Standard Vite SPA rewrites (/* ➔ /index.html) mistakenly returned HTML text for API calls, causing JSON parsing crashes. Implemented negative lookahead regex in vercel.json: "source": "/((?!api/).*)", preserving API routes while serving SPA pages.
3. jsQR Camera Stream Freezing Scanning non-JSON QR codes threw unhandled exceptions, breaking requestAnimationFrame and freezing the camera stream. Refactored scanner with React useRef locks; scheduled requestAnimationFrame unconditionally on every frame with error isolation.
4. Rapid Duplicate Scanning & SMS Spam Processing video at 60 FPS triggered 10+ duplicate scan events per second when a student held a card in front of the lens. Added a 2000ms temporal debounce cooldown and payload comparison, guaranteeing exactly one attendance entry and SMS dispatch.
5. Misleading Arrival Reassurance Conventional apps broadcast a generic "Bus reached school" alert, misleading parents of absent children into thinking their ward arrived. Formulated an automated dual-cohort algorithm: safely boarded students receive green arrival SMS, while unboarded students trigger an urgent red "Bus Missed" alert.
6. Zero-Phone Commute Constraint Rural students cannot carry smartphones, and parents have basic 2G feature phones without data packages or app stores. Standardized on durable laminated 2D QR passes with sub-second driver scanning and direct cellular GSM SMS delivery requiring zero mobile data.
Conclusion: Through 12 comprehensive operational modules and a dedicated Zero-Phone Architecture, SchoolRoute TN successfully proves that enterprise-grade commuter safety, real-time tracking, and automated parent communication can be achieved for public school education without burdening rural families with smartphone costs.
